# Roblox Sports Cars Project

Проект спортивных автомобилей в Roblox Studio с реалистичной физикой, звуками и минималистичным спидометром.

## Особенности проекта
- **Спорткары:** 3 машины (красная, белая, синяя) со свободной расстановкой и полным приводом.
- **Посадка в авто:** клавиша `[F]` на водительской двери (ProximityPrompt).
- **Выход из авто:** безопасная телепортация снаружи рядом с дверью водителя.
- **Освещение и сигналы:**
  - `L` — включение/выключение фар (SpotLight + Neon + щелчок тумблера)
  - `Q` — левый поворотник
  - `E` — правый поворотник
  - `X` — аварийная сигнализация (все 4 поворотника)
- **Звуки:** запуск двигателя со стартером, мягкий холостой ход, реалистичный разгон с повышением оборотов и плавный накат.
- **Спидометр:** минималистичный темный HUD снизу по центру с индикатором скорости KM/H, передач (R/N/D) и поворотников.

## Синхронизация через Rojo и Radmin VPN
1. Установите Rojo CLI:
   ```bash
   winget install Rojo.Rojo
   ```
2. Запустите Rojo для совместной работы в локальной сети:
   ```bash
   rojo serve --address 0.0.0.0 --port 34872
   ```
3. Подключитесь в Roblox Studio через плагин Rojo:
   - Хост: `localhost:34872`
   - Друг через Radmin VPN: `<Ваш_Radmin_IP>:34872` (например `26.134.8.166:34872`)
